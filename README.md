# Mobile Sales Data Dashboard | Power BI

## Project Overview

This project presents an interactive Mobile Sales Data Dashboard built with Microsoft Power BI to analyze sales performance, transaction activity, mobile model performance, customer ratings, and regional distribution.

The dashboard transforms sales data into visual insights that help users explore performance across different months, mobile brands, models, payment methods, and locations.

## Business Problem

Mobile sales data can be difficult to interpret when sales, transactions, product performance, and customer feedback are viewed separately.

This project brings these metrics together in an interactive dashboard to support faster performance monitoring and data-driven business decisions.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Excel / source datasets
- Data cleaning, transformation, and visualization

## Dashboard Features

- **Sales KPIs:** Total sales, total quantity, transaction count, and average price.
- **Monthly Analysis:** Compare quantity trends across months.
- **MTD Analysis:** Explore month-to-date sales progression.
- **Product Performance:** Compare sales across mobile models and brands.
- **Payment Analysis:** Understand transaction distribution by payment method.
- **Customer Ratings:** Analyze good, average, and poor ratings.
- **Regional Analysis:** Explore geographic sales distribution.
- **Interactive Filters:** Analyze the data using available month, year, brand, mobile model, and payment method filters.
